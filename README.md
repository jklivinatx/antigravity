# Antigravity Workspace

This repository stores custom Antigravity agent skills, rules, automation scripts, and project workflows.

## Custom Skills

- **[youtube-mp3-downloader](.agents/skills/youtube-mp3-downloader/SKILL.md):** Reusable workflow for downloading YouTube videos and extracting high-quality MP3 audio directly to `C:\Users\cary\Downloads\`.

## Setup & Requirements

- Python 3.x (`yt-dlp` package installed)
- `ffmpeg` (for media encoding/conversion)
